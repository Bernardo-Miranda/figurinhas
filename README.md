# Papercraft Pro

Site estático pronto para deploy na Vercel.

## Estrutura

- `index.html`: página principal
- `assets/css/styles.css`: estilos
- `assets/js/main.js`: interações, contador, social proof e links de checkout
- `assets/img/`: imagens extraídas do HTML original
- `index.inline-backup.html`: backup da versão original em arquivo único

## Deploy na Vercel

Importe esta pasta como projeto na Vercel. Não precisa de build command.
